GitHub Pages Setup Guide

How to host this tool for free and enable scheduled posting.

🎉 Total cost: ₹0. GitHub Pages hosting is free. Instagram Graph API is free. GitHub Actions scheduling is free.
📋 Part 1 — Host on GitHub Pages
1

Create a GitHub Repository

Go to github.com/new and create a public repo. Name it something like instaflow.

2

Upload index.html

Upload the index.html file (this tool) to the root of your repository. You can drag and drop it in the GitHub UI.

3

Enable GitHub Pages

Go to Settings → Pages, set Source to Deploy from a branch, choose main branch and / (root). Click Save.

4

Access Your Tool

Your site will be live at https://yourusername.github.io/instaflow within ~2 minutes.

📱 Part 2 — Get Instagram API Access (Free)
1

Convert to Instagram Business/Creator Account

In the Instagram app → Settings → Account → Switch to Professional Account. Choose Business or Creator.

2

Create a Facebook App

Go to developers.facebook.com/apps/create → Select "Business" app type → Fill details → Create App.

3

Add Instagram Graph API Product

In your app dashboard → Add Product → Find Instagram Graph API → Set Up.

4

Get a Long-Lived Access Token

Go to Graph API Explorer → Select your app → Generate token with permissions: instagram_basic, instagram_content_publish. Then exchange for a long-lived token (valid 60 days).

5

Get Your Instagram Business Account ID

In Graph API Explorer, query: me/accounts then use the page ID to query {page-id}?fields=instagram_business_account. Copy the id value.

6

Enter in Setup Tab

Paste your Access Token and Account ID in the Setup tab and click Connect!

⚡ Part 3 — Enable Scheduled Posting (GitHub Actions)

Create this file in your repo to auto-post on schedule:

name: Instagram Auto-Post

on:
  schedule:
    - cron: '*/15 * * * *'  # Runs every 15 minutes to check
  workflow_dispatch:         # Manual trigger

jobs:
  post:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Check and Post Scheduled Posts
        env:
          ACCESS_TOKEN: ${{ secrets.INSTAGRAM_ACCESS_TOKEN }}
          ACCOUNT_ID: ${{ secrets.INSTAGRAM_ACCOUNT_ID }}
        run: |
          python3 post_scheduler.py

Create post_scheduler.py in your repo:

import os, json, requests
from datetime import datetime, timezone

ACCESS_TOKEN = os.environ['ACCESS_TOKEN']
ACCOUNT_ID = os.environ['ACCOUNT_ID']
QUEUE_FILE = 'queue.json'

def load_queue():
    if not os.path.exists(QUEUE_FILE):
        return []
    with open(QUEUE_FILE) as f:
        return json.load(f)

def save_queue(queue):
    with open(QUEUE_FILE, 'w') as f:
        json.dump(queue, f, indent=2)

def post_to_instagram(item):
    base = f"https://graph.facebook.com/v19.0/{ACCOUNT_ID}"
    # Step 1: Create media container
    params = {
        'access_token': ACCESS_TOKEN,
        'caption': item.get('caption', ''),
    }
    if item['type'] == 'REELS':
        params['media_type'] = 'REELS'
        params['video_url'] = item['media_url']
        params['share_to_feed'] = 'true'
    else:
        params['image_url'] = item['media_url']

    r = requests.post(f"{base}/media", params=params)
    data = r.json()
    if 'id' not in data:
        print(f"Error creating container: {data}")
        return False

    container_id = data['id']

    # Step 2: Publish
    r2 = requests.post(f"{base}/media_publish", params={
        'creation_id': container_id,
        'access_token': ACCESS_TOKEN
    })
    result = r2.json()
    print(f"Published: {result}")
    return 'id' in result

now = datetime.now(timezone.utc).timestamp()
queue = load_queue()
changed = False

for item in queue:
    if item.get('status') == 'scheduled':
        if float(item.get('scheduled_ts', 0)) <= now:
            success = post_to_instagram(item)
            item['status'] = 'posted' if success else 'failed'
            changed = True

if changed:
    save_queue(queue)
    # Commit changes back to repo
    os.system('git config user.email "action@github.com"')
    os.system('git config user.name "GitHub Action"')
    os.system('git add queue.json')
    os.system('git commit -m "Update queue status after posting"')
    os.system('git push')
💡 Add your secrets: Go to repo → Settings → Secrets and variables → Actions → Add INSTAGRAM_ACCESS_TOKEN and INSTAGRAM_ACCOUNT_ID.
